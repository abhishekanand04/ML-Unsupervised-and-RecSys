# ML-Unsupervised-and-RecSys

Repository: Collection of unsupervised learning and recommender system projects, notebooks, and utilities.

Contents
- Notebooks demonstrating clustering, dimensionality reduction, and anomaly detection.
- Recommender system examples (collaborative filtering, matrix factorization, content-based).
- Example datasets and data-preprocessing scripts.

Usage
1. Browse the notebooks in the `notebooks/` directory.
2. Run the preprocessing scripts in `scripts/` to prepare datasets.
3. See each subdirectory for README/help specific to that module.
